# Cover letter kit: setup (5 minutes)

Two files: **instructions.md** (the rules) and **portfolio.md** (our projects with links).

## If you can create Projects in Claude (recommended)

1. In Claude, open **Projects → New project**, name it "Cover letters".
2. Open the project's **instructions** and paste the whole of `instructions.md`.
3. Add `portfolio.md` to the project's **files / knowledge**.
4. Start a chat inside the project and paste the job post, e.g.
   "Write a cover letter for this job, signed by Yulia: …"

## If you can't create Projects

Start a new chat, attach both files, and write:
"Follow instructions.md and use only the projects in portfolio.md. Write a cover letter
for this job, signed by [name]: …"
Do this at the start of every new chat.

## Tips

- Always say who signs the letter; Claude will ask if you forget.
- Read the letter before sending: check the links open and the cases fit the job.
- New portfolio projects: check the Portfolio page in Notion. When you get an updated
  `portfolio.md`, replace the old file in the project.
